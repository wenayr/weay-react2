# v3.0.0

Date: 2026-09-06

The package-surface follow-up of the 2026-09-01 architecture review: every runtime name now
has a canonical subpath, the persistence layer is its own storage-neutral block
(`wenay-react2/persist`), and the root barrel is demoted to a compatibility union. No import
breaks, nothing is removed or renamed. Full root -> subpath map:
`doc/WENAY_REACT2_RENAMES.md`, section "3.0.0 entry map".

## Why a major

- The canonical map changed. Before 3.0.0, 71 runtime names (buttons, modal, menu, params,
  chart, settings/toolbar/slot, the ag-grid style helpers, `logsApi`, `updateBy`,
  `floatingWindowMap`, ...) existed only on the root; `__test/barrelParity.test.ts` carried
  them as a frozen `ROOT_ONLY` list. That list is now empty and asserted empty: a new module
  has to pick its subpath, and the root cannot grow on its own.
- The root is deprecated. `import {...} from "wenay-react2"` keeps resolving to the same
  bindings in 3.x (the parity test asserts `root[name] === subpath[name]` for every name),
  but the union will be trimmed in the next major. Consumers get one major to move.
- A version that changes what "canonical" means, even without a breaking import, is a
  contract change under the Compatibility Policy in `doc/PROJECT_FUNCTIONALITY.md`, so it is
  cut as a major rather than hidden in a minor.

## Persistence block

`wenay-react2/persist` (`src/persist/index.ts`) is the storage-neutral persistence layer,
three layers bottom up:

- `ObservableMap` - a Map that announces mutations; every persisted slot is one.
- `CacheStorage` + `createCacheMapWithStorage(maps, storage)` - the adapter contract and the
  diff/serialize loop over it. `localStorageCache` is the browser default.
- `memoryCache` - the module-level registry over the four persisted maps
  (`floatingWindowMap`, `mapResiReact`, `mapRightMenu`, `buttonStatusMap`) plus the free-form
  `memoryProps` slot behind `memoryGetOrCreate` / `memorySet` / `memoryUpdate`. Components
  import their map from here; the app wires load/save once with `useCacheMapPersistence`.

`memoryCommit(key, entry, mutate?)` is the one commit idiom: mutate, `renderBy(entry)`,
`memoryMarkDirty(key)`, return the entry. `memoryUpdate` and
`createPersistedController().commit` both delegate to it (this closes the
"`memoryUpdate` over `persistedController.commit`" follow-up; the module cycle is gone because
the idiom lives in `memoryStore` itself). `createSearchHistory` is the smallest consumer.

The storage adapter contract, as shipped:

```ts
interface CacheStorage {
    set(key: string, value: object): Promise<boolean>
    get<T extends object>(key: string): Promise<T | null>
    delete(key: string): Promise<boolean>
    setRaw?(key: string, payload: string): Promise<boolean>   // optional fast path, pre-serialized JSON
}
```

React Native (or any host without `localStorage`) supplies the same three async methods; the
block itself never touches the DOM:

```ts
import AsyncStorage from "@react-native-async-storage/async-storage"
import {createCacheMapWithStorage, memoryMaps} from "wenay-react2/persist"

const asyncStorageCache: CacheStorage = {
    async set(key, value) { await AsyncStorage.setItem(key, JSON.stringify(value)); return true },
    async get(key) { const raw = await AsyncStorage.getItem(key); return raw ? JSON.parse(raw) : null },
    async delete(key) { await AsyncStorage.removeItem(key); return true },
    async setRaw(key, payload) { await AsyncStorage.setItem(key, payload); return true },
}
const cache = createCacheMapWithStorage(memoryMaps, asyncStorageCache)
await cache.load()
```

The root surface gained `createPersistedController`, the four persisted maps, `memoryCommit`
and the saved-state types (they were reachable only by deep path or not at all before);
`./react` keeps re-exporting the 2.x memory/cache names so existing subpath code stays put.

## Migration (one major to do it)

Replace root imports with subpath imports; the bindings are identical, so this is a
find-and-replace per name. The full table is in `doc/WENAY_REACT2_RENAMES.md`; the shape:

| Root name (deprecated path) | Canonical |
| --- | --- |
| `Button`, `Overlay`, `createToolbar`, `SettingsDialog`, `createUiSlot`, `FResizableReact`, ... | `wenay-react2/ui` |
| `ModalProvider`, `useModal`, `confirmModal`, `FreeModal`, `TextInputModal`, `LeftModal`, ... | `wenay-react2/modal` |
| `Menu`, `contextMenu`, `createContextMenu`, `DropdownMenu`, `useRightMenuController`, ... | `wenay-react2/menu` |
| `ParamsEditor`, `ParamsEdit`, `ParamRow`, `setAutoStepForElement`, ... | `wenay-react2/params` |
| `Sparkline`, `createChartEngine`, `createDataSet`, ... | `wenay-react2/chart` |
| `GridStyleDefault`, `StyleGridDefault`, `StyleCSSHeadGrid`, `StyleCSSHeadGridEdit` | `wenay-react2/grid` |
| `logsApi`, `getLogsApi`, `PageLogs`, `MiniLogs`, `MessageEventLogs` | `wenay-react2/logs` |
| `updateBy`, `__observerStateForTests` | `wenay-react2/react` |
| `floatingWindowMap` | `wenay-react2/windows` (also `/persist`) |
| `memoryCache`, `memoryGetOrCreate`, `memoryUpdate`, `createCacheMapWithStorage`, `useCacheMapPersistence`, ... | `wenay-react2/persist` (`/react` re-exports stay) |

Rule of thumb: the CSS import does not change (`wenay-react2/styles` once); a file that mixes
blocks imports from several subpaths; the root is only for code you are not touching yet.

## Internal file moves (deep imports were never supported)

- `src/internal/utils/{memoryStore.tsx, cache.ts, persistedMaps.ts, persistedController.ts,
  observableMap.ts, floatingWindowTypes.ts, searchHistory.ts}` and
  `src/internal/hooks/useCacheMapPersistence.ts` -> `src/internal/persist/`. `utils/` is now
  persistence-free; `persist/` imports `renderBy` from `updateBy` and nothing from
  `components/`.
- New entry files `src/{persist,params,modal,menu,chart,ui}/index.ts`, each an explicit
  named-export list with a header docblock stating what the entry pulls (the package probe
  rejects `export *` in canonical entries).
- `src/api.tsx` docblock rewritten: the root is a compatibility union; sections unchanged.
- `__test/barrelParity.test.ts`: `ROOT_ONLY` is `[]` and asserted so.
- `scripts/ag-grid-bundle-probe.mjs`: `assertBoundary` for the six new entries.
