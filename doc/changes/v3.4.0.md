Date: 2026-09-10

- Raise the dependency and peer minimum for wenay-common2 from ^2.17.0 to
  ^2.20.0; the lockfile resolves the published 2.20.0 package, without local overrides.
- Adopt common2's PC1 terminal peer-close and PC2 dynamic RPC subscription cleanup
  fixes. This dependency update needs no React workaround or new transport.

  versions already present in this repository.

  Raw dynamic callback subscriptions do not automatically retry on reconnect. SC1
  resources (2.19.0) use stable status Stores and new remotes per generation; keep
  readiness/permissions/generation separate in React. No additional resource hook added.

  useAiRunClient exposes the existing run data, including recovery facts, without
  assuming authority to resume external effects. H1/H2 remain upstream proposals.

## R4: free-position keyboard gestures

  a real-button handleProps, live inputMode, and onDragCancel. Existing imports/row
  bindings and delta-based callbacks remain compatible; keyboard is off by default.

  Cancel/unmount detach listeners before callbacks; late releases cannot commit.
  StrictMode cleanup uses the same retained controller, without resetting an idle seed.
- Space/Enter begin/confirm, arrows move, Escape/blur cancel. trackState:false stays
  imperative for keyboard too. Position setters are silent and do not end a gesture.

  timed permission cancellation and a public connection snippet. Constraints and changed-only
  saves are consumer code; no RPC, room, coordinate protocol or domain policy added.

  its front position after drop/cancel. Toolbar buttons expose covered notes, and layer
  labels show the order without remounting notes or changing saved coordinates.
  Layer follow-up verified with typecheck, 14 focused tests and browser full-overlap
  switching A/B; the saved position and single commit remain unchanged by layer buttons.
- Migration: after publication remove only Note's keyboard ref/key handler and input
  arbitration, use handleProps and onDragCancel. Retain base/revision/generation, permissions,
  scroll conversion, constraints, presence and commit. No example package was patched.

  Browser QA58: keyboard preview/Shift/confirm/Escape/focus, independent text/delete,
