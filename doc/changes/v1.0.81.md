# v1.0.81

Date: 2026-08-08

- Added: explicit `core`, `react`, `grid`, `windows`, `logs`, and expanded
  `communication` package entrypoints. The root entry remains the complete 1.x
  compatibility facade; canonical entrypoints exclude demos and known legacy
  wrappers.
- Changed: every runtime export path now has a `types` condition, an ESM import
  target, and a default target. A package probe verifies that the copied
  `dist/package.json` preserves those conditions and that every target exists.
- Improved: runtime imports now use supported `wenay-common2/client` and feature
  subpaths. The representative root `memoryCache` bundle dropped from about
  444 KB to 193 KB minified.
- Refactored: the workflow/AI React adapters now close the render-to-effect
  subscription window and tag `ready`, `error`, and `lastEvent` with their
  client identity. A replacement client can no longer render lifecycle or event
  state from the previous account/client.
- Refactored: lazy submenu, renderer, and focus loaders share one guarded async
  lifecycle. Rejections are reported through `onActionEvent`, stale completions
  are ignored, and handled menu failures no longer become unhandled promises.
- Refactored: floating-window persisted geometry lives in a data-only contract
  leaf instead of creating a type dependency cycle between the window,
  desktop-manager, and persistence layers. The unused non-public duplicate chart
  engine was removed; the public React engine remains unchanged.
- Fixed: `LocalStorageCache.deleteAll()` removes only keys owned by its instance
  instead of globally clearing application storage. Input and Other actions now
  render semantic `type="button"` controls.
- Fixed: incoming and outgoing peer calls now share one subscription registry;
  manager replacement/unmount releases every listener, late same-id settlements
  cannot remove a replacement call, and readiness comes only from the matching
  `manager.ready`. Presence snapshots are reconciled with newer online/offline
  edges instead of overwriting them.
- Fixed: `useColumnGrid` disposes its committed controller on real unmount while
  tolerating the StrictMode effect replay. `useUpdateBy` now supplies an SSR
  snapshot, and multiple `useKeyboard` consumers on one target share one native
  listener and one global keyboard event.
- Fixed: the shared AG Grid baseline registers `RowAutoHeightModule`, which is
  required by the shipped logs and MiniLogs column definitions. The live QA
  archive no longer reports AG Grid error #200 when those tables mount.
- Fixed: the AI workflow QA card mutates the live Store and flushes it before
  semantic events. `VideoCall` no longer renders a dead voice control, exposes
  live assistant status semantics, and its browser speech demo safely detaches
  handlers and handles start/stop failures.
- Verification: strict entrypoint typecheck, clean package build, package
  manifest/target probe, packed TypeScript/esbuild consumer smoke, and bundle
  boundary probe. The probes confirm that the headless core is React/ag-grid-free
  and canonical feature imports exclude unrelated subsystems. Added regression
  coverage for workflow races, peer/presence cleanup, grid disposal, SSR,
  assistant controls, menu async errors, keyboard listener sharing, and the
  row-auto-height module contract. The interactive QA stand was also exercised
  across workflow, peer, grid, settings, windows, calls, menus, charts, keyboard,
  and logs surfaces with a clean final browser console.
