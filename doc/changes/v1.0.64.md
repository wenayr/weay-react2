# v1.0.64

Date: 2026-07-25

- Updated: `wenay-common2` from `^1.0.94` to `^2.0.0`.
- Migrated: Store Replay React hooks and route controllers now consume the
  sole V2 facade directly. `onBatch` observes applied V2 envelopes and
  `validateBatch` can reject an envelope before it mutates a store.
- Removed upstream: RPB/1-RPB/3, MessagePack, legacy Store Replay lines,
  numbered batch codecs and wire negotiation. JSON arrays are the only RPC
  application wire in common2 2.x. The deprecated React `batch` option remains
  only as an ignored source-compatibility field.
- Fixed: Observe-store hooks close the render-to-effect subscription gap and
  prevent stale async mirror generations from leaking after unmount, stop, or
  restart.
- Fixed: Cache API persistence uses a stable project request key, migrates the
  previous full-location key, and no longer forks data across SPA paths or
  hashes.
- Hardened: `updateBy` uses an SSR-safe layout effect and reports a bounded
  trigger-pass diagnostic instead of recursing indefinitely.
- Refactored: the QA board is split into a registry, shared stand kit, and
  subsystem cards without changing the public `wenay-react2/demo/stand`
  surface. Card 24 now demonstrates the invariant Store Replay mode `"v2"`.
- Fixed: npm package `main` and `types` now point at the shipped
  `lib/index.js` and `lib/index.d.ts` instead of the nonexistent nested
  `dist/` directory, restoring directory/import tooling that does not resolve
  the package `exports` map first.
- Verification: 33 Jest suites / 122 tests, clean TypeScript/package build,
  packed-artifact entry/type checks, and an esbuild consumer smoke-test over
  the unpacked tarball. Visible-browser QA confirmed live Store Replay V2
  mutation/catch-up and the video-call lobby with no console errors.
