# v1.0.71

Date: 2026-08-03

- Updated: the minimum `wenay-common2` version is now `2.6.0`.
- Added: `useStoreLazyLineSync` and `useStoreLazyLineMirror`, React lifecycle
  wrappers for progressive, resumable top-level Store synchronization on slow
  links. Mirror state and the subscriber cursor survive StrictMode restarts and
  enabled toggles.
- Adopted: the reconnect QA replay now declares a ten-minute `keepMs` retention
  target, bounded by its existing 20,000-envelope hard cap, and reports the
  observable journal window.
- Upstream: common2 also adds progressive Store Lazy Line delivery, time-based
  replay retention, and internal dynamic-runtime work with no public API break.
- Verification: strict TypeScript checks, Jest (including lazy fill and live
  convergence), clean package build, bundle probe, packed-artifact inspection,
  running QA stand, and registry metadata checks.
