# v2.2.0

Date: 2026-09-06

Bundle pass: the subpath entries no longer pull the `wenay-common2/client` barrel. No public
API change; the minor bump marks the measurable size change for consumers.

## The finding

`wenay-common2` ships as CommonJS. A bundler cannot tree-shake a CommonJS barrel, so importing
ONE helper from `wenay-common2/client` (`waitRun` in updateBy, `deepClone` in memoryStore,
`listen` in columnState/Toolbar/useKeyboard, `sleepAsync`/`promiseProgress` in the menu,
`round`/`decimals` in inputAutoStep, `colorGenerator2` in LeftModal) cost the entire barrel:
RPC client, media, exchange bars, time formatting - about 181 KB raw / 61 KB gzip. Because
updateBy is reached by every entry, every entry paid it. The v2.1.0 note that an upstream
`sideEffects: false` would fix this was wrong: that flag only helps ESM. The upstream fix is an
ESM build or narrow entries.

## What changed

- `updateBy`: local trailing-drop throttle with the exact `waitRun().refreshAsync` semantics.
- `memoryStore`: local `utils/deepClone.ts` (objects, arrays, Date, Map, Set, cycles, bound functions).
- `columnState`, `Toolbar`, `useKeyboard`: `listen` now comes from the narrow `wenay-common2/listen`
  entry (2.5 KB gzip). Same function, same `ListenApi` types - the public `onChange` surface is unchanged.
- `menu`, `RightMenu`: local `utils/async.ts` (`sleepAsync`, `promiseProgress`).
- `inputAutoStep`: local `round`/`decimals`. `LeftModal`: local `utils/colorGenerator.ts`.
- `scripts/ag-grid-bundle-probe.mjs`: the core/react/grid/windows/communication entries now FAIL
  the build if the client barrel (`lib/client.js`, `Common/rcp/`, `Exchange/`) comes back.
- `__test/localHelpers.test.ts` pins the local helpers against the real common2 implementations
  (deepClone incl. cycles, promiseProgress counters and lazy start, colorGenerator2 sequence).

## Measured (esbuild, minified, gzip)

| entry | 2.1.1 | 2.2.0 |
|---|---|---|
| `wenay-react2/react` (createUpdateApi) | 64.8 KB | 4.4 KB |
| root utility path (memoryCache) | 65.8 KB | 5.5 KB |
| `wenay-react2/windows` (FloatingWindow) | 86.0 KB | 25.6 KB |
| `wenay-react2/core`, `/grid`, `/communication` | unchanged (never reached the barrel) |
| `wenay-react2/logs` | 61.4 KB | 61.4 KB - see below |

## Still open

- `./logs` and `ParamsEditor` still need `Params` (`GetSimpleParams`, `mergeParamValuesToInfos`,
  the param types), which only exists behind the client barrel. Upstream: a narrow `./params`
  entry (like `./listen`) or an ESM build; then `./logs` drops to a few KB as well.
- The root barrel keeps everything by design; apps importing subpaths get the numbers above.
