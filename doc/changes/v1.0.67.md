# v1.0.67

Date: 2026-07-27

- Fixed: `react` and `react-dom` are no longer production dependencies of the
  published package. They remain `^19.2.0` peer dependencies, so Bun and other
  package managers reuse the consumer application's React runtime instead of
  installing a library-owned copy.
- Preserved: `react-dom` remains an optional peer for the DOM/CSS/AG Grid-free
  `wenay-react2/native` entrypoint. Public exports, facades, types, and runtime
  behavior are unchanged.
- Development: React and React DOM `^19.2.8` are now development dependencies
  used only to build, type-check, and test the library.
- Verification: library build, strict TypeScript checks, Jest, web/native
  entrypoint audits, packed-artifact inspection, and Expo SDK 57 consumer
  installation/export/doctor checks.
