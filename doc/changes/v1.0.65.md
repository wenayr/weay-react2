# v1.0.65

Date: 2026-07-25

- Updated: `wenay-common2` from `^2.0.0` to `^2.1.1`. Release `2.0.1`
  removes unused test/build dependencies, updates Axios to `1.18.1`, moves its
  toolchain to TypeScript 7 and `tsx`, adds an RPC guard scanner API, and uses
  deterministic Node 24 npm-CI verification. Release `2.1.1` clarifies the
  declaration-first workflow and primitive/facade construction rules, retains
  semantically class-shaped models, and restructures the internal Node HTTPS
  resource without changing its public manager interface.
- Migrated: the project now builds and type-checks with
  `typescript@7.0.2`. Module resolution uses `Bundler`; `rootDir` and ambient
  `types` are explicit; CSS side-effect imports have an ambient module
  declaration compatible with TypeScript 7 defaults.
- Updated: React/ReactDOM `19.2.8`, AG Grid `36.0.2`, Vite `8.1.5`,
  `@vitejs/plugin-react` `6.0.4`, Jest `30.4.2`,
  `jest-environment-jsdom` `30.4.1`, current React/Node/Jest type packages,
  and all other used direct dependencies to their latest registry versions.
- Simplified: Jest now compiles TypeScript/TSX through SWC. The Babel pipeline
  and `ts-node` were removed, avoiding Babel 8's ESM/runtime transition in this
  CommonJS Jest configuration.
- Removed as unused: `@testing-library/jest-dom`,
  `@testing-library/user-event`, `ajv`, `dotenv`, `react-test-renderer`, the
  project-local `npm` package, and `ts-node`.
- Added: `npm run typecheck` covers both the library/QA sources and Jest tests.
  Store Replay tests now use the canonical common2 2.x
  `Observe.StoreReplayRemote` type.
- Adopted: common2's generated-declaration rule. `lib/**/*.d.ts` is now
  explicitly documented as generated and read-only; `npm run types:generate`
  regenerates declarations after public type changes, while
  `npm run types:watch` keeps them current during iteration.
- Fixed: generated declarations now ship per-asset `*.css.d.ts` companions
  for public CSS side-effect imports without requiring consumer flags. Declaration
  generation and full builds validate the emitted entrypoints under strict
  TypeScript 7 consumer settings, catching missing packaged type support.
- Revalidated: a fresh registry update confirms `wenay-common2@2.1.1`,
  `react@19.2.8`, and `react-dom@19.2.8` are still the latest stable releases;
  the common2 dependency and lockfile were refreshed.
- Verification: TypeScript 7 source/test type-check; 33 Jest suites / 122
  tests; clean package build; declaration generation and watch startup;
  peer/outdated dependency checks; packed entry/type/changelog checks; and an
  esbuild consumer smoke-test over the unpacked tarball. Visible-browser QA
  confirmed Store Replay V2 mutation, AG Grid 36 rendering, and creation of a
  live video-call room with no console errors.
