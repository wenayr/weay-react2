# v1.0.79

Date: 2026-08-05

- Fixed: `FloatingWindow` now hydrates geometry and Snap membership when the
  application's `memoryCache` finishes loading after the window has mounted.
  Session persistence therefore works across a real page reload, not only a
  component remount in the same runtime.
- Improved: the QA board exposes a top-level `Desktop windows` shortcut. Its
  direct URL scrolls to card 52 and launches the two-window desktop demo with
  taskbar, cascade, session Snap, and Win/Meta keyboard hints immediately.
- Verification: 37 Jest suites / 146 tests, strict TypeScript checks, clean
  package build, bundle probe, and browser verification of Meta+Right followed
  by a full reload and restored right-half geometry.
