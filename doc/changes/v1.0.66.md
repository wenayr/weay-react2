# v1.0.66

Date: 2026-07-26

- Fixed: `AgGridTable`, `useAgGrid`, and `GridStyleDefault` no longer retain or
  register `AllCommunityModule`.
- Added: a centralized default AG Grid module baseline for the features used by
  the library and its main applications: client-side rows and transactions,
  row/column/event/render/scroll APIs, column autosize, row selection,
  text/number/date filters, row/cell styling, and tooltips.
- Preserved: `AgGridTable` still accepts AG Grid's standard `modules` prop for
  optional per-grid features. `defaultAgGridModules` and
  `ensureAgGridModules()` are exported for bare `AgGridReact` integrations.
- Changed: `GridStyleDefault()` now configures only the shared theme and global
  grid options. Default feature registration is idempotent and occurs before
  the first `AgGridTable`/`useAgGrid` grid is created.
- Added: AG Grid development validation is enabled only in non-production
  builds and is removed by the production build's `NODE_ENV` replacement.
- Fixed: the package declares CSS as its only side-effectful module class, so a
  tree-shaken root import such as `memoryCache` no longer retains AG Grid.
- Added: module-registration regressions and a reproducible esbuild probe for
  AllCommunity vs targeted sizes, production validation removal, and a
  grid-free root utility import.
- Dependencies: verified against the registry on 2026-07-26; AG Grid
  `36.0.2` remains the current release, so no newer compatible package version
  was available to install.
