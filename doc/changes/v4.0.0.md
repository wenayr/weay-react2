# v4.0.0 — rootless package, legacy names, common2 3.0.0 and wenay-exchange

Date: 2026-09-24

A permanent major migration note. Migrating a 3.x consumer is one CLI run:
`doc/WENAY_REACT2_RENAMES.md`, "4.0.0 migration cut". Source: the 2026-09-23 library review,
the root trim announced in 3.0.0, and the owner's requests of 2026-09-24 ("fix the main part",
"update wenay-common2, we also need wenay-exchange", "do 4.0.0"). The unreleased 3.6.0 work is
part of this version.

## Breaking

- The root entry `wenay-react2` is removed: no `"."` export, `main` or `types`. It was the
  deprecated compatibility union of 3.x; every name lives on the canonical subpaths.
- Renamed: `renderByRevers` → `renderByReverse`, `mapResiReact` → `resizableSizeMap`,
  `mapRightMenu` → `rightMenuMap`, `FResizableReact` → `ResizableBox`, `CResizeObserver` →
  `ResizeObserverHub`, `memorySet` → `memorySetIfAbsent` (same set-if-absent behaviour). The
  `memoryCache` storage scopes keep their old strings, so saved sizes and menus still load.
- Removed from `./react`: `__observerStateForTests` (a test probe).
- Signatures: memory API keys are `string` (were `any`); the `memoryGetOrCreate` option is
  `reverseDeep` (was `reversDeep`); `createColumnState().api.onChange` and
  `createToolbar().api.onChange` are read-only `ListenLike` views `{on(cb, opts?) -> off}`
  instead of the raw common2 `ListenApi` (`.on` and `useListenEffect` keep working, `emit` and
  `close` are gone); `FloatingWindowController.onResize*` use this package's own
  `FloatingWindowResizeHandler` / `FloatingWindowResizeStartHandler` instead of react-rnd types,
  and `FloatingWindowUpdate.dir` is `FloatingWindowResizeDirection`. The public declarations no
  longer name react-rnd, so the resize library can change without another major.
- Peers: `wenay-common2@^3.0.0` (was `^2.21.1`) and the new `wenay-exchange@^1.0.0`.
  `@babel/parser` is no longer a runtime dependency (an optional peer for the migration CLI).

## Migration CLI

`scripts/migrate-root-imports.mjs` (shipped) now also applies the 4.0.0 renames, for root and
subpath imports and re-exports, as `{new as old}` so code below the imports compiles unchanged.
A removed name stops the batch with a diagnostic. Without `@babel/parser` the CLI exits 2 with
an install hint. Covered by 17 node tests and by the packed-consumer probe, which runs the CLI
from the extracted tarball.

## Dependencies

- common2 3.0.0 moved the exchange data (`Bars`, `CQuotesHistory*`, `CBar*`, `OHLC`,
  `CTimeSeries*`, `createRandomBars`, `LoadQuoteBase`, ...) into `wenay-exchange` under the same
  names; `TF`, `Period`, the time API and `Params` stay in common2. This package imports none
  of the moved names and re-exports none of them. Reviewed 2.21.2 (Observe parent-replacement
  fix, transparent here) and 2.21.3 (documentation only).
- `wenay-exchange` is a dependency and peer, the same one-copy policy as common2
  (`Bars.TF === TF`); applications import exchange data from `wenay-exchange`.
- `pnpm-workspace.yaml`: release-age exclusions for `wenay-common2@3.0.0` and
  `wenay-exchange@1.0.0`; lockfile updated with the global pnpm 11.14.

## VideoCall

- New `labels?: Partial<VideoCallLabels>` with `videoCallLabelsRu` (the default) and
  `videoCallLabelsEn` on `./communication`. Every visible and assistive text, including
  `assistantCommands`, comes from labels. The default output is byte-identical to 3.5.1,
  checked against 16 snapshots recorded before the change.
- Fix: room sizes in the rooms panel used a fixed plural ("1 участников").
- JSX split into readable lines (longest line 1328 → 221 characters).
- QA card 60 (`#video-call-labels`).

## Package and build

- `doc/target/**` and `doc/progress/**` (maintainer backlog and working notes, 16 files in the
  published 3.5.1) no longer ship; the packed-consumer probe fails if they return. The tarball
  went from 440 KB to about 390 KB.
- Cross-platform build: `scripts/build-fs.mjs` replaces `rd /s /q` and `xcopy`, forward-slash
  paths replace `.\dist`; the packed-consumer probe extracts with relative paths, so it no
  longer depends on which `tar` comes first in PATH.
- GitHub Actions CI (`.github/workflows/ci.yml`): frozen pnpm install, both TypeScript
  configs, Jest, full build with probes, bundle boundaries, migration CLI tests.
- Entry sizes (gzip, one name imported): `./logs` 64.5 → 61.1 KB and `./params` 71.8 → 68.2 KB
  (common2's client barrel no longer carries exchange code); `./communication` 8.0 → 8.8 KB (the
  Russian labels dictionary; the English set is tree-shaken unless imported).

## Documentation

- `doc/QUICKSTART.md`: install, six everyday snippets and which state model to use; its

- Rare doc: entry points without a root, "Module-level state" (duplicate package copies, SSR,

## Internal

- Deleted with the root: `src/index.ts`, `src/api.tsx`, the internal `utils/index.ts` barrel,
  the unused `chartEngineReact.tsx` barrel, `scripts/generate-root-barrel.mjs`,
  `scripts/root-deprecation-probe.mjs`.
- `__test/barrelParity.test.ts` / `barrelTypeParity.test.ts` now assert that names shared by
  several entries are the same bindings and types, that `./native` stays disjoint, that the cut
  names do not return, that there is no root entry, and that the window resize types still fit
  react-rnd.
- The QA stand imports the public entries instead of the root barrel.
- `useFloatingWindowController`: drag flags `a` / `b` → `mouseDragging` / `touchDragging`.
