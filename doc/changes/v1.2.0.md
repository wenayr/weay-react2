# v1.2.0

Date: 2026-08-23

- Changed (additive, hence minor): `contextMenu.Layer`'s item provider is now `other(gesture)` with `gesture = {x, y, target, pointer}` and may return `{items, source}`; `getState().windowPortal` names the `FloatingWindow` layer hosting an open menu. Zero-argument providers and array returns keep working.
- Changed: horizontal viewport clamp for root menus; a menu opened from a floating window renders inside that window's own isolated layer instead of under it or clipped by its overflow; touch long press is served by the gesture-aware provider instead of the `contextMenu.map` queue. QA card 53 is the acceptance card.
- Reason: the three context-menu requests from the lanaFour overlay audit of 2026-08-23.
- Verification: 56 Jest suites / 252 tests, both typecheck configs, probes, the three scenarios driven on the live stand.
- v1.2.1 (same day) is a byte-identical republish; published versions are immutable, so it only takes a version the registry accepts.
