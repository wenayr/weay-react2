# v3.3.0

Date: 2026-09-09

- R1: useReorder/useReorderBoard expose item.handleProps for real buttons, with native
  focusability, pressed/disabled state and touch-action. Existing row props retain their
  interactive-child filter. Space/Enter begin/confirm; arrows change slots (board Left/Right
  crosses columns); Escape/cancel/blur/touchcancel discard the preview. Data/order changes
  and canDrag revocation invalidate all input modes. A changed drop calls commit once.
- Restore focus to the committed handle, including cross-column remount. Keep the real
  keyboard handle in source layout and expose a viewport overlay for its destination.
  Consumers hide the original ONLY for pointer mode, never the keyboard-focused handle.
- R3: opt-in autoScroll {edge, maxSpeed, canScroll}, nearest permitted scrollable per axis,
  clipped ancestor bounds, limited frame step and half speed under reduced motion. Actual
  ancestor scroll deltas adjust targeting/source transforms without moving the pointer overlay.
  Stop the frame loop on drop/cancel/unmount; no loop by default. No new DnD dependency.
- Move board FLIP measurements to a layout effect and preserve scroll positions while
  applying/reverting temporary geometry. Generic drag release listeners run in capture so
  nested controls cannot swallow release. Pre-hold cleanup no longer races a native drop.
- R2: export ServiceCommandCall<C> and add controller.runTuple(call), preserving correlated
  names/argument tuples and exact known-command results. Direct run remains unchanged;
  both paths share the same lock/error state and one request ID, with no automatic retry.
- Active QA card 57 is an organizer-shaped local consumer with nested vertical/horizontal
  scroll, separate inputs/actions, permission toggle, keyboard instructions/live status,
  consumer overlay and a command tuple forwarded through two components without casts.
- Scope: react2 only. common2 remains 2.17.0; no app/scaffold/role/domain changes or local
  package replacement. The deployed organizer/pizzeria has not been upgraded or certified here.

Consumer cleanup after installing 3.3.0: in shared/react/command-action.ts replace the local
tPayload/tCommandCall conditional types with ServiceCommandCall<C>, and the cast execute
with controller.runTuple. Keep the app's boolean result/error-message policy if desired.
Replace the organizer's span handle with a named button using handleProps; add announcements,
the pointer-only source visibility rule and an explicit autoScroll allow-list. No whole app
adapter file is automatically redundant, and none was deleted from examples in this release.

Verification: 68 suites / 362 tests passed, including mouse/touch button starts, keyboard
cancel/commit/focus, revocation/removal/unmount/pre-hold cleanup, captured release, scroll
geometry, nested permitted edges, reduced-motion speed and stopped frame loops. Compile-only
two-component/generic tuple forwarding rejects wrong names/inputs and keeps exact results.
Typecheck and generated declarations validated. Browser: keyboard reorder/cancel/cross-column
focus, pointer drop, independent inputs/actions, revocation, vertical edge scroll, horizontal
edge scroll at 390px, disabled scroll and stopped scrolling. Fresh reload and final gestures
have no new console errors (a development hot-reload hook-order warning required reloading
after adding hooks). Actual touch hardware/screen reader and deployed-app acceptance remain
consumer checks, not claimed here. Full build and package/bundle probes checked before publish.
