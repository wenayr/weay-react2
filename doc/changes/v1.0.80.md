# v1.0.80

Date: 2026-08-06

- Improved: the top-centre Snap picker now presents four coherent Windows-style
  layout presets with 2, 3, 3 and 4 targets. The final preset is a true 2x2
  layout whose four corners are independently hoverable and clickable.
- Changed: maximize/restore remains available through title double-click, two
  taps, keyboard commands and the headless controller, but its title-bar button
  is hidden by default. Set `maximizeButton` to opt into that control.
- Added: `minimizeButton={false}` hides the title-bar minimize control without
  disabling taskbar, keyboard or controller minimization. Close, minimize and
  maximize chrome are therefore all consumer policy.
- Verification: 37 Jest suites / 148 tests, strict TypeScript checks, clean
  package build, bundle probe, and browser QA of the four-corner drop target,
  double-click restore, hidden B control and taskbar restoration.
