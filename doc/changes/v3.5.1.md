# v3.5.1 — restore AG Grid baseline

- Restore `RowStyleModule` and `TooltipModule` in `defaultAgGridModules` so
  `AgGridTable` / `useAgGrid` support the documented row styling and tooltips
  without consumer-supplied modules. Optional per-grid modules remain supported;
  `AllCommunityModule` is not enabled.
- History: both modules were deliberately removed in 2.1.0, commit `5c9db54`,
  as a bundle optimization based on library-internal use. That change was recorded
  in the original 2.1.0 release note (later pruned from the rolling history), but
  broke the documented consumer baseline and remained present through 3.5.0.
- Regression checks: require both modules in the default list and render a real
  public `AgGridTable`, without a `modules` prop or mocked grid, asserting
  `getRowStyle` changes the row and `tooltipValueGetter` produces a visible tooltip.
  Both checks first failed against 3.5.0, including AG Grid's missing-module error.
- Verification: both TypeScript configs; 72 Jest suites / 380 tests, plus 14 migration
  CLI checks; full build with generated declarations and packed-consumer probes;
  bundle boundary checks. Targeted grid bundle is 259,949 bytes gzip (previously
  255,674), still below AllCommunity's 319,979 bytes.
