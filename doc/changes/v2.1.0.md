# v2.1.0

Date: 2026-09-02

Performance pass after the 2.0.0 cut: three read-only audits (runtime hot paths, React render
efficiency, bundle size) and the fixes they justified. Two documented surface changes, the rest
is internal.

## Changed surface (documented, minor)

- `VideoCall` styles moved out of `wenay-react2/styles` into `wenay-react2/styles/communication`
  (new export). The block was a quarter of the stylesheet and only `./communication` needs it;
  apps rendering `VideoCall` add the second import. Rename map updated.
- ag-grid baseline modules: `TooltipModule` and `RowStyleModule` dropped from
  `defaultAgGridModules` (no tooltip or row-style option is used anywhere in the library).
  Consumers who use them pass the module through `AgGridReact`'s `modules` prop, the pattern the
  agGrid4 README already prescribes. Measured: targeted grid bundle 259.9 -> 255.7 KB gzip.
- `columnBuffer.setNames` is a no-op when the deduped name list is unchanged; `apply()` stays
  the explicit force path. A stream re-announcing the same dynamic columns no longer rebuilds
  the grid's columnDefs per tick.
- Additive: `CacheStorage.setRaw?` (raw JSON write); `useStoreKeys({mode})`; logs controller
  `onChange` event, `getLastChange()`, `LogsChange` type and `lastChange` on full/mini state;
  `useLogsPageTable().resync()`.

## Runtime hot paths

- Persistence save: stringify -> parse -> stringify per scope became one stringify through
  `setRaw`; `saveDebounced` keeps a pending timer of the same delay instead of clearing and
  re-arming per dirty key (a burst is written `delay` after its first change).
- Grid overlay buffer: `gridHas` no longer falls back to an O(rows) `forEachNode` scan on every
  miss when the api has `getRowNode`; `updateData` reuses the node it already resolved.
- Column state: `known` key set hoisted to controller creation; `commit()` and the per-frame
  `columnMoved` preview path normalize once instead of two to five times.
- Logs: per-entry grid delivery is O(1) (add + evicted rows in one transaction, driven by the
  controller's change record) instead of a full O(total logs) reconcile per log; the full
  reconcile survives as `resync()` on grid attach. Notifications are capped at `maxVisible`
  with their timers cleared. `MessageEventLogCard` memoized, payload text computed once.
- `updateBy`: no subscriber-set copy when there is one subscriber.
- `MyResizeObserver`: parent rect read once, binary search (<= 4 probes) instead of 8 linear
  probes, each a forced reflow.
- Context-menu stats: no snapshot clone when nobody listens.

## React render

- Window drag: viewport clamp (rect + querySelectorAll) skipped during drag/resize and re-run
  once on release; mouse/touch moves coalesced into one commit per animation frame.
- Desktop: a raise re-renders only the windows whose stack slot changed (per-window
  `useSyncExternalStore` over a memoized `{index, zIndex, active}` tuple), not every window.
- `createColumnGrid`: grid handlers are factory-lifetime, `tableProps()` memoized, so
  `memo(AgGridTable)` finally holds across controls/toolbar re-renders.
- `CardList` rows memoized and sorted once per data/sort; `ColumnsMenu` item model memoized,
  buttons memoized with cached drag handlers; `MenuItemWrapper` memoized so hover does not
  re-render every item.
- Toolbar: one normalize per `Bar` render; FLIP does one read pass then one write pass.
- SettingsDialog: section search text cached per section, filter fed from a deferred search
  value. `useReorder`: FLIP measurement moved from render into a layout effect; string-join
  preview key replaced by an element-wise compare.

## Bundle

- Stand-only CSS (QA showcase, card-47 chrome looks, video rubric, Wenay Calls landing) moved to
  `src/stand/stand.css`; seven orphaned classes deleted. Library stylesheet 85.7 -> ~51 KB raw.
- `scripts/ag-grid-bundle-probe.mjs` boundary regexes pointed at `src/internal` / `src/stand`
  (they matched nothing after 2.0.0, so the boundary checks were vacuous).
- Not fixable here: `wenay-common2` has no `sideEffects` declaration, so any single helper from
  `wenay-common2/client` costs ~61 KB gzip in every entry that touches it (`./react`, `./logs`,
  root). One line in common2's package.json; tracked in `doc/target/my.md`.

- Verification: both typecheck configs, 57 Jest suites / 288 tests (13 new), `npm run build`
  with declaration check and both package probes, bundle probe with live boundary assertions,
  QA stand on a clean tab without console errors.
