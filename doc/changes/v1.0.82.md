# v1.0.82

Date: 2026-08-12

- Updated: the minimum `wenay-common2` version is now `2.10.0`; existing root,
  client, media, peer, observe, replay, and contract integrations remain
  compatible and require no React API changes.
- Compatibility: the minimum Node.js version is now 20, matching the direct
  dependency. `wenay-common2` uses global WebCrypto for artifact hashing and no
  longer supports Node 18.
- Available upstream: explicit opt-in console caller annotations through
  `wenay-common2/debug-console`; focused `listen`, `rpc`, `server/fs`,
  `server/auth`, `server/http`, and `server/webhook` entrypoints; precise
  clone return types; and replay storage keyframe types that correctly allow
  `undefined`.
- Fixed upstream: observer failures no longer reclassify already committed
  contract or dynamic-host transitions, sibling observers still receive the
  event, and a failing Store current-value callback removes its new
  subscription.
- Verification: all 42 Jest suites and 164 tests, strict TypeScript checks,
  clean production package build, package entrypoint probe, packed TypeScript
  and esbuild consumer probe, and bundle boundary probe passed on Node 24.
