# v2.0.0

Date: 2026-09-02

Architecture pass (review of 2026-09-01: four zone readers + package-surface reading),
shipped as a deliberate migration cut. The owner's call: the API may break as long as it is
documented. Full old -> new map: `doc/WENAY_REACT2_RENAMES.md`, section "2.0.0 migration cut".

## Breaking

- Package surface: no entrypoint imports CSS any more - apps import `wenay-react2/styles` once
  (plus `styles/menu-right` for RightMenu). Root `kit` namespace removed (it pinned every
  member for bundlers). `./lib/common/api.js` deep export and `./demo/stand` removed;
  `socket.io-client` no longer an optionalDependency. `./demo/peer-media` and
  `./demo/peer-conference` stay published (from `lib/stand/demo/`).
- Layout: `src/common/src` -> `src/internal`, `src/common/api.tsx` -> `src/api.tsx`; the QA
  stand, VideoMeetingPlatform and demos live in `src/stand/` and are not compiled into `lib/`
  (only the two demo entrypoints are). 91 files had imports rewritten mechanically.
- Removed exports (dead, demo or duplicate; see the rename map for replacements):
  `createRightClickMenu`/`MenuR`, `StickerMenu`, `RightMenuDemo`, `OutlineDragDemo`,
  `ApiLeftMenu` singleton, `TestLeft333`, `LogsPage`, the whole `logsContext` stack
  (`LogsProvider`, `LogsTable`, `LogsNotifications`, `LogsSettings` component, `MainPage`,
  `AppLogs`), `myChart/1` (`createChartCanvas`, `ChartDemo`), `MyChartEngine`,
  `generateIncrementalData`, `applyGridRows`, `ArrayPromise`, `PageVisibility*`, `DragArea`,
  `map3`/`mapWait`, cache internals from the root barrel, deprecated aliases `onCLickClose`
  and `keySave`, `StyleOtherRow`/`StyleOtherColumn`.
- `utils/index.ts` is an explicit export list; `updateBy`'s third listener channel is gone
  (`api.on` shares the imperative callback set).
- Barrel type parity: `LogEntry`, `LogInput`, `LogsSettings` no longer diverge between the root
  and `./logs`; the parity test asserts equality instead of listing exceptions.

## Additive

- `Overlay` exported (scrim stack + Escape arbitration, so app dialogs can join it);
  `BuildAgThemeOptions`; `useContextMenuGesture`; `GridStyleDefault` now builds on
  `buildAgTheme('dark', {browserColorScheme: false})` with identical params.

## Internal restructuring (non-breaking part of the same pass)

- Changed: `FloatingWindow.tsx` (1044 lines) is now a re-export façade over
  `useFloatingWindowController.ts`, `FloatingWindowBase.tsx`, `floatingWindowPersistence.ts`
  (map read/repair/hydration), `floatingWindowSnap.ts` (pure snap/detach arithmetic),
  `floatingWindowDrag.ts` (the document pointer loop) and `floatingWindowProps.ts` (types).
  Every extracted hook keeps its position in the hook sequence and its dependency array.
  `WindowChrome` takes its controller type from `floatingWindowProps` (breaks a would-be
  import cycle). The `Dnd/FloatingWindowTypes.ts` shim is gone; Dnd imports
  `utils/floatingWindowTypes` directly.
- Changed: `chartEngineReact.tsx` (1297 lines) is a barrel over `dataSet.ts`, `panels.ts`,
  `renderer.ts`, `interaction.ts`, `engine.ts`, `MyChartEngine.tsx` and an internal `axis.ts`.
  The engine's container sizing goes through `canvasSurface.observeElementBox` instead of a
  third private `ResizeObserver`; DPR deliberately not added (all draw paths and the layer
  blit are in raw bitmap pixels).
- Changed: one pure column-state core, `src/native/columnStateCore.ts` (no imports), shared by
  `createNativeColumnState` and the DOM `createColumnState`; `utils/fixedOrder.pinFixedOrder`
  delegates to it. The core is imported by path, so `./native` gains no names and the
  root/native zero-overlap rule holds. Two real divergences were parameterized rather than
  unified (`fallbackToDefaults` for a missing `order`/`visible`: native keeps `def`, web keeps
  `[]`/`{}`); three were accidental drift and take the web behaviour. Known web-only wart kept
  as-is: `toggleSort('unknown')` clears the current sort (native guards it).
  `__test/nativeColumnParity.test.ts` now pins grouped visible defaults, width validation,
  filter keys, groups clamping and the full sort cycle.
- Changed: `hooks/useOutside.tsx` holds only the hook. `OutsideClickArea` moved to
  `components/OutsideClickArea.tsx`; the `Button`/`HoverButton`/`OutsideButton`/
  `AbsoluteButton` family (with its `buttonStatusMap` persistence) to
  `components/Buttons/Button.tsx`, next to `MiniButton`, which already built on it. The
  dependency arrow is components -> hooks again. All names stay on the root barrel.
- Changed: `menu/useContextMenuGesture.ts` is the one right-click / long-press / double-click
  recogniser; `contextMenu.Layer` and `MenuR` spread its handlers instead of carrying two
  copy-pasted blocks with a "keep in step" comment.
- Changed: `SettingsDialog` layout writes and `createToolbar.setConfig` go through
  `persistedController.commit` instead of six hand-rolled `render()` + `memoryMarkDirty` pairs;
  the component layer no longer imports `memoryMarkDirty`.
- Changed: `components/Other.tsx` and `components/Parameters.tsx` (ParamsEditor wrappers and
  row renderers with one consumer) folded into `components/ParamsEditor/` as
  `asyncEditors.tsx` / `paramRows.tsx`; `components/ParamsEditor/index.ts` re-exports all.
- Changed: `useCacheMapPersistence` moved from `utils/cache.ts` to
  `hooks/useCacheMapPersistence.ts`; `utils/` is hook-free (it still imports `renderBy` from
  updateBy - the remaining reason persistence sits in `./react` rather than `./core`).
- Changed: `grid/columnState/index.ts` exports state only; the DOM renderers
  (`ColumnsMenu`, `ColumnDots`, `CardList`) ship from `grid/columnState/ui.ts`. Root re-exports both.
- Fixed: `tsconfig.test.json` included a non-existent `src/styles.d.ts`; now `src/style/*.css.d.ts`.
- Changed: `.idea/` untracked and ignored (machine-specific, like `.vscode` and `.claude`).
- Docs: `doc/changes` entries backfilled for 1.1.1, 1.2.0/1.2.1, 1.2.2, 1.2.3, 1.2.4 from the
  release commits; the seven oldest files removed per the 10-file rule.
- Verification: both typecheck configs, 55 Jest suites / 267 tests (two suites deleted with
  their modules, 8 parity tests added), `npm run build` including generated-declaration check,
  entrypoint probe and packed-consumer probe (run from PowerShell; Git Bash `tar` cannot
  take a `C:` path), QA stand on a clean tab without console errors.
