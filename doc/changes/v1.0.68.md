# v1.0.68

Date: 2026-07-28

- Updated: the minimum `wenay-common2` version is now `2.1.3`, so mobile
  consumers cannot resolve an older common2 release through this package.
- Fixed: RPC path proxies now work on React Native Hermes runtimes that do not
  provide `WeakRef` or `FinalizationRegistry`, through the compatibility
  fallback shipped by common2 `2.1.3`.
- Preserved: React and React DOM remain peer dependencies and are not installed
  as library-owned production runtimes.
- Verification: dependency lock refresh, strict TypeScript checks, Jest, clean
  package build, packed-artifact inspection, and registry metadata checks.
