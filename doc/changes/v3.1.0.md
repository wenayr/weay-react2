# v3.1.0

Date: 2026-09-08

- Preserve `StoreReplayRemote<T>` through sync, mirror, per-key and route hooks. Destination
  state cannot be widened by an incompatible remote, and `switchRoute` retains the controller's
  state type. Per-key callback values infer from typed remotes. Previously erased upstream
  `any` remains an explicit compatibility escape hatch; incorrect typed pairings now fail.
- Expose `chunkedKeyframe` across all five Store Replay hooks: automatic/disabled mode,
  `budgetBytes` and `onProgress`. Inline object/callback changes do not resubscribe; mode/budget
  changes do, with the usual `keepSeq` policy. Suppress progress from closed subscriptions.
  Snapshot assembly, fallback and transport ownership remain in common2.
- Add active QA card 55: live inventory loading, progress, 16/64 KiB budgets, single snapshot,
  stock updates and leaving during a pending load. Update brief/rare docs and the functionality map.
- Add consumer-owned drag overlay geometry to `useReorder` and `useReorderBoard`. Card 27
  portals both dragged cards and complete columns outside clipping/scroll containers, preserves
  source layout, and shows the target in a status line. Existing inline transforms stay compatible.
  Regression checks cover viewport coordinates under scale, mouse/touch, drop and unmount cleanup.
- Verification: public API compile-time rejection/inference cases, real chunk-facade integration
  tests (all five hooks, StrictMode, latest callback, unmount, route handoff and old-host fallback),
  64 Jest suites / 323 tests, typecheck/generated declarations/build/package probes, and live
  browser QA (96 items; 24 parts at 16 KiB / 6 at 64 KiB; single snapshot, live updates, unmount;
  card transfer between populated columns and whole-column reordering).
