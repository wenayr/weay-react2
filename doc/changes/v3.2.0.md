# v3.2.0

Date: 2026-09-09

- Update dependency/peer range to published wenay-common2 2.17.0. Its service scaffold owns
  reactive permissions, token renewal and failover; React observes existing Stores/events.
- Add useOwnedClient: keyed/enabled ownership of sync or async factories, readiness method
  or promise, abort on cleanup, exactly-once disposal, explicit close and stale-result fencing.
- Add useAsyncAction: a synchronous single-flight lock, typed result, original error,
  explicit clearError and generation/unmount fences, without automatic retries.
- Add structural useServiceCommands: inferred command names/argument tuples/results and
  one injected request ID (crypto.randomUUID by default) per accepted invocation.
  No scaffold imports, server authorization, application roles or domain logic.
- Add active QA card 56 using real common2 Store/Replay, account switches, pending startup/actions,
  duplicate clicks, failures and resource cleanup; update public usage/ownership docs.

- Fix FloatingWindow drag termination: capture mouse/touch release before menus or controls
  can stop propagation; flush the last queued move and clear the drag state. Ignore right/middle
  mouse presses on the title bar.
- Fix contextMenu.Layer processing the same right-click through both contextmenu and mouseup.
  Opening now uses the native contextmenu event only; release over the newly opened popup no
  longer replaces row actions or closes the menu. Keep the existing left-double-click/touch paths.
- Replace card 53's misleading static drag target with an edge target in the real floating
  window, a clear 42px title handle, scoped opaque skin, position feedback and an edge-test button.
  Default library window styling remains unchanged.
- Verification: regressions first reproduced the drag/menu failures; mouse and touch release,
  non-primary buttons, both native right-click event orders, browser edge clamping and repeated drag.
  Full suite: 66 suites / 343 tests, typecheck and generated declaration validation passed.
  Includes actual common2 AI client ownership, Store updates and subscription disposal.
  Browser: popup bounds stay within the bottom/right edges, title drag works before/after
  the menu, close/reopen works. Card 56: one task on double-click; original error/clear;
  account switch during action/readiness, disable/re-enable, close/recreate and navigation
  with pending work. No console errors. The local fixture does not claim server/network QA.
  Full build, packed consumer (TypeScript, Node ESM and bundler resolution), public entrypoint
  and bundle-boundary probes passed; the npm payload contains the new runtime/declarations.
