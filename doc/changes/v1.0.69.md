# v1.0.69

Date: 2026-07-30

- Updated: the minimum `wenay-common2` version is now `2.2.1`.
- Adopted: common2's RPC authorization lifecycle. Token providers and renewal,
  auth-state events, correlated reauthentication, server-driven revocation,
  and clean termination of Listen streams after principal narrowing now flow
  through existing React subscription lifecycles without a second transport
  owner in this package.
- Improved: consumers receive common2's default compact-row RPC encoding and
  lazy Replay slow-client gate; request batching remains an application-owned
  opt-in.
- Updated: the common2 runtime now includes Axios `1.19.0`; local Node type
  declarations and esbuild were refreshed to their current releases.
- Verification: strict TypeScript checks, Jest, clean package build,
  bundle probe, packed-artifact inspection, and registry metadata checks.
