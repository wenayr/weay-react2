# v1.0.78

Date: 2026-08-05

- Added: an optional, compact `FloatingDesktop` layer with a shared window
  taskbar, minimize/restore actions, active-window ordering, and a headless
  manager API for fully consumer-owned rendering.
- Added: cascading initial placement and Windows-style `Meta+Arrow` snap,
  maximize, restore, unsnap, and minimize behavior without expanding the core
  `FloatingWindow` component into a desktop shell.
- Added: `layoutGroup` persistence for Snap membership and the corresponding
  free geometry, so grouped windows recover their arrangement across remounts
  and sessions.
- Improved: QA card 27 now demonstrates compact item creation, draggable column
  containers with consumer-owned headers, per-column controls, and preservation
  of items when a column is deleted.
- Verification: 37 Jest suites / 145 tests, strict TypeScript checks, clean
  package build, bundle probe, and interactive browser QA on cards 27 and 52.
