# v2.2.1

Date: 2026-09-06

Regression sweep over the 2.0.0 / 2.1.x / 2.2.0 waves, plus the one regression it found.

## Fixed

- The Communication barrel (`internal/components/Communication/index.ts`) still carried
  `import "../../../style/style.css"`. The root entry re-exports that barrel, so every bundler
  that honours CSS imports got `style.css` (~38 KB) back as a side effect of importing anything
  from `wenay-react2` - the opposite of the 2.0.0 contract ("no entrypoint imports CSS, apps
  import `wenay-react2/styles` once"). The `./communication` subpath was not affected (it
  re-exports `VideoCall.js` directly). Import removed; `__test/noCssSideEffects.test.ts` scans
  the library sources so it cannot come back.

## Verified (no regressions found)

- Published package `wenay-react2@2.2.0` installed from the registry into a scratch consumer:
  every `exports` entry imports in Node ESM (DOM-free ones) or bundles with esbuild, all style
  entries resolve, `tsc` with `skipLibCheck: false` passes against the shipped types, and
  `createUpdateApi` from `./react` bundles to 1.2 KB gzip without the common2 client barrel.
- QA stand, fresh tab, no console errors and no window `error`/`unhandledrejection`:
  modal (open, Escape), SettingsDialog (open, search hit, two-stage Escape), createToolbar
  (+1 item), Toolbar over columnState (hide/show column mirrors to the grid), columnState 28
  (hide / sort / reset / unmount / remount), 29 dots -> cards, 32 table/cards, Grid Chrome
  (popover, command feedback, mount/unmount), FloatingWindow (open A/B, minimize, close),
  context menu (layer, inside a window, close on outside), RightMenu (hover, submenu, leave),
  OutsideClickArea, useReorderBoard (+item/+col), Params sliders (number <-> range),
  Sparkline canvases, Peer SDK / presence / calls (ring, accept, hang up), Contract runtime,
  packet mesh, Observe local store, callbackHub. Archive: reactivity card (renderBy semantics
  with the local throttle), keyboard API, agGrid4 controller (add / update / remove / unmount
  / buffer write / remount catch-up), overlay rowData, dynamic column buffer, logs table, chart.
- Timer-driven cards (replay / SSE mirror / media capture) were not judged from the browser:
  the pane was hidden, which freezes rAF and throttles timers; they are covered by the Jest
  replay/observe suites (all green).
- New unit test `__test/gridBufferRemount.test.ts` pins the detach -> buffer write -> attach
  catch-up of `createGridBuffer`.
