# v3.5.0 — migration support and common2 2.21.1

Source: lanaFour's 1.2.2 → 3.4.0 migration audit, 2026-09-10.

- Updated `wenay-common2` dependency and peer minimum from ^2.20.0 to ^2.21.1;
  lockfile uses the exact published 2.21.1 (no local substitution). Reviewed 2.21.0's
  resource scope/reconciler and 2.21.1's chunks-first test-double clarification.
  No mandatory React hook change; ownership/retry policy remains with the consumer.

- Fixed all four CSS subpaths with a first `types` condition and empty side-effect
  declaration, retaining the CSS default. No consumer ambient modules or triple-slash
  references required. Internal `.css.d.ts` files stay for direct stylesheet imports.
- Restored the original v2.0.0 migration note. Major migration guides are now permanent,
  in addition to the ten recent ordinary release notes.
- Corrected removed logs/outside/menu names in the rare guide; LogsPage's migration points
  to the actual public `logsApi.React.Setting`, not an unavailable named InputSettingLogs.
- Restored `restoreDates` on `/persist` (and the compatibility root), sharing the cache's
  pure implementation. Restores nested array string elements too, is safe for cycles and
  existing Dates. Mutates writable JSON-shaped input, returns void, does not validate a
  domain schema or infer date-only/timezone-offset strings. QA card 59 exercises `/persist`.
- Shipped `scripts/migrate-root-imports.mjs`: preview, `--write`, `--check`, derived public
  name/type map, deterministic duplicate priority, aliases, comments, type-only imports and
  re-exports. Unsupported cases stop the batch before writes; regex/string contract tests
  need manual review. Added `@babel/parser` as a CLI-only dependency (no UI runtime import).
- Generated root re-exports have per-name `@deprecated` annotations, verified through
  TypeScript language-service suggestions for values AND types. Canonical imports remain
  unmarked. Whole-export/file comments alone do not suffice; `tsc` does not turn suggestions
  into errors. Use codemod `--check` as the migration gate.
- Preserved previously root-only `FloatingDesktopEntry` / `FloatingDesktopStack` types by
  giving them a `/windows` home; no previous root export removed, `/native` unchanged.

Verification (common2 2.21.1): both TypeScript configs; 71 Jest suites / 379 tests;
14 migration CLI cases; generated root value/type language-service deprecation probe;
full build and packed-consumer checks (all four CSS imports with Bundler, vite/client
and noUncheckedSideEffectImports, shipped CLI and v2.0 guide); bundle-boundary probe.
Browser card 59 passed after a fresh Vite restart: field/array Dates, unchanged date-only
text, preserved references, no console errors. CSS TS2882 was first reproduced on the
previous packed 3.4.0. No downstream lanaFour repository was modified.
